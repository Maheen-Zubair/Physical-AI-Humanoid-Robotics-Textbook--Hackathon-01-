Module 1 References

This page provides academic citations and additional resources for the ROS 2 fundamentals covered in Module 1.

Official Documentation​

Open Robotics. (2024). ROS 2 Documentation: Humble Hawksbill. Retrieved from https://docs.ros.org/en/humble/

Open Robotics. (2024). ROS 2 Tutorials. Retrieved from https://docs.ros.org/en/humble/Tutorials.html

Open Robotics. (2024). rclpy API Reference. Retrieved from https://docs.ros2.org/latest/api/rclpy/

Object Management Group. (2015). Data Distribution Service (DDS) Specification, Version 1.4. Retrieved from https://www.omg.org/spec/DDS/

Foundational Papers​

Macenski, S., Foote, T., Gerkey, B., Lalancette, C., & Woodall, W. (2022). Robot Operating System 2: Design, architecture, and uses in the wild. Science Robotics, 7(66), eabm6074. https://doi.org/10.1126/scirobotics.abm6074

Quigley, M., Conley, K., Gerkey, B., Faust, J., Foote, T., Leibs, J., Wheeler, R., & Ng, A. Y. (2009). ROS: an open-source Robot Operating System. In ICRA Workshop on Open Source Software (Vol. 3, No. 3.2, p. 5).

Maruyama, Y., Kato, S., & Azumi, T. (2016). Exploring the performance of ROS2. In Proceedings of the 13th International Conference on Embedded Software (pp. 1-10). https://doi.org/10.1145/2968478.2968502

Books​

Koubaa, A. (Ed.). (2020). Robot Operating System (ROS): The Complete Reference (Volume 5). Springer. https://doi.org/10.1007/978-3-030-45402-9

Fairchild, C., & Harman, T. L. (2017). ROS Robotics By Example (2nd ed.). Packt Publishing.

Joseph, L. (2018). ROS Robotics Projects (2nd ed.). Packt Publishing.

Recommended Reading Order​

For deeper understanding, we recommend exploring these resources in order:

  1. Start with: ROS 2 Documentation tutorials (hands-on practice)
  2. Then read: Macenski et al. (2022) for architectural understanding
  3. For DDS details: Pardo-Castellote (2003) and eProsima documentation
  4. For advanced topics: Koubaa (2020) edited volume

Citation Format​

When citing this textbook module:

Author. (2024). Module 1: ROS 2 Fundamentals. In Physical AI & Humanoid Robotics: A Practical Guide. Retrieved from [URL]
